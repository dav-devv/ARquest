# Monitores virtuais do Windows

O ARquest controla monitores virtuais já instalados, mas não inclui o driver nem seu instalador. Baixe o pacote oficial do [Virtual Display Driver](https://github.com/VirtualDrivers/Virtual-Display-Driver/releases) diretamente do projeto upstream. Leia as instruções e confira as assinaturas dos arquivos antes de instalar. A instalação do driver de vídeo requer privilégios de administrador; o projeto ARquest não altera configurações de segurança do Windows.

Sem o driver, é possível transmitir monitores físicos e janelas de aplicativos que o Windows já disponibiliza.
