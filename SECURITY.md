# Segurança

Não publique vulnerabilidades exploráveis, certificados, chaves privadas, tokens de pareamento ou dados pessoais em issues públicas.

Use o recurso **Report a vulnerability** na aba Security deste repositório, se estiver habilitado. Caso contrário, entre em contato em privado com a manutenção pelo perfil GitHub `dav-devv`. Inclua passos para reproduzir e uma versão afetada; não inclua dados de usuários.

Arquivos `pc_server/cert.json` são gerados localmente para HTTPS e nunca devem ser versionados. Os binários oficiais do driver de vídeo não fazem parte do código-fonte deste repositório.
